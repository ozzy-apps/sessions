Make music from the first clip to the final mix.

- Session clips and scenes, a complete Arrangement timeline, audio/MIDI recording and automation.
- Osmium wavetable synth, Drum Studio, sampled instruments, guitar processing and 63 built-in devices.
- Download/Postpone/Skip startup update checks, with a manual check and an opt-out in Preferences.
- Sample-pack downloads in Help → Sample Packs; optional drums are a separate download.

Choose the package for your system: Debian/Ubuntu `.deb`, portable Linux AppImage, Flatpak bundle, or Windows ZIP. SHA256SUMS lists the exact downloads. Install updates after saving and closing Sessions.

Linux is the established platform. The Windows build uses shared Windows audio and Windows MIDI; physical audio/controller testing is still needed before describing it as production-ready. ASIO and plugin hosting are not included.

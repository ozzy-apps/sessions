# Osmium — Drum & Bass

40 factory presets at 174 BPM. Search **Osmium** in Browser → Sounds or type a name in Osmium's patch selector.

Eight macros, in order: **Tone · Warp · Drive · Width · Space · Echo · Body · Air**. Body adds an octave below; Space/Echo add wet signal while preserving the dry attack. Subs start centered with no reverb or delay. Their Width macro adds optional gentle chorus.

Pads: hold open chords around MIDI 52–72 (E2–C4 in Sessions). Leads: MIDI 55–79. Bass/subs: MIDI 28–43 (E0–G1), then transpose to the track. All rhythmic movement follows project tempo.

Portable `.sessionspreset` files use the original Osmium device format and also load in Sessions 0.27/0.28. Unzip the Presets folder and drag a file onto a MIDI track, or place the files in your User Library preset folder. The factory bank is built into Sessions 0.29; installation requires no file copying.

The audition reel contains each preset in the order below, with four-note pad chords and short bass/lead phrases. It uses a shared playback gain; individual patches are not peak-normalized. The MP3 adds the same 8 dB preview gain to every patch; preset levels are unchanged.

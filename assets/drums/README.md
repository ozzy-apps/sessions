# Sessions Acoustic Collection

Recorded samples by Glen MacArthur, AVL Drumkits / Bandshed Records, 2015–2023.
https://www.bandshed.net/avldrumkits/

Sources (downloaded 2026-10-18):
- https://www.bandshed.net/sounds/AVLDrumkits_SFZ/BLACK_PEARL_2023_repack.zip
- https://www.bandshed.net/sounds/AVLDrumkits_SFZ/RED_ZEPPELIN_2023_repack.zip
- https://www.bandshed.net/sounds/AVLDrumkits_SFZ/BLONDE_BOP_SFZ.zip

This collection is a selected, remapped subset, distributed under a different name
as requested by the author. WAV recordings are unmodified. Each articulation has
five recorded velocity layers. These are velocity layers, not round robins.
GM mapping replaces AVL's nonstandard keys: 35 aliases kick, 48/50 use a pitched
rack tom, 52 maps the china. The upstream SFZ is not used or included.
Six mixer/tuning recipes use three recorded kits: Studio Rock / Tight Pop use
Black Pearl, Vintage / Metal / Big Room use Red Zeppelin, Jazz uses Blonde Bop.
Additional overhead and room controls are modeled ambience, not separately
recorded microphone channels. No claim of affiliation or endorsement is made.
